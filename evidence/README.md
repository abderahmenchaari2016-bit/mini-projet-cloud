# Preuves de vérification

Les fichiers texte et JSON de ce dossier ont été produits par les commandes Docker et les réponses HTTP réelles du prototype le 20 novembre 2026.

- `hello-world.txt` : sortie de l'image officielle `hello-world`.
- `docker-ps.txt` et `docker-compose-ps.txt` : état réel des conteneurs au moment du contrôle.
- `docker-compose-build.txt` et `docker-compose-up.txt` : reconstruction des images et démarrage avec Compose.
- `smoke-test.txt` : résultat lisible des contrôles de santé, de création de commande et de communication inter-services.
- `demo-results.json` : réponses JSON obtenues auprès des services pendant le même parcours.

Les captures d'écran de Docker Desktop, du terminal, de l'application et de l'événement associé doivent être prises sur le poste de présentation. Aucune image synthétique n'est présentée comme capture d'écran.
